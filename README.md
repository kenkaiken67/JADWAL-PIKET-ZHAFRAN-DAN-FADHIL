# 🧹 Jadwal Piket Kelas (XI RPL)

Proyek ini adalah desain antarmuka pengguna (UI) berbasis web statis yang menampilkan **Kartu Jadwal Piket Kelas**. Didesain dengan gaya modern, warna-warna cerah, dan sedikit sentuhan humor internal kelas untuk membuatnya lebih menarik.

## ✨ Fitur Utama

* **Modern Card Layout**: Menggunakan tata letak kartu yang bersih (*clean*) dengan bayangan halus (*box-shadow*) agar elemen terlihat timbul dan elegan.
* **Vibrant Gradient Background**: Latar belakang menggunakan kombinasi warna gradasi hijau dan merah muda (`linear-gradient`) yang *eye-catching*.
* **Custom List Styling**: Daftar nama anggota piket didesain khusus menggunakan kotak berlatar belakang terang dengan aksen garis solid di sebelah kiri (`border-left`), memberikan kesan rapi dan terstruktur.
* **Humorous Touch**: Menambahkan *easter egg* atau candaan internal kelas (seperti catatan khusus untuk Habsi yang jarang piket ✌️).

## 🛠️ Teknologi yang Digunakan

* **HTML5**: Struktur dan semantik kerangka kartu jadwal.
* **CSS3**: *Styling*, tata letak terpusat (*Flexbox*), gradien warna, dan desain elemen daftar (*list*).
